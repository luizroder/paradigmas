1. Genealogia das linguagens de programação

A genealogia das linguagens não é uma escada de progresso porque uma linguagem nova não necessariamente substitui uma linguagem antiga. Muitas linguagens continuam sendo utilizadas mesmo depois do surgimento de alternativas mais modernas.

Dois fatores históricos que permitem que uma linguagem influencie outra são a necessidade de resolver novos problemas e a evolução das tecnologias de hardware e software. Assim, uma linguagem pode introduzir uma ideia que será aproveitada por outras, mesmo que ela própria deixe de ser popular.

2. Plankalkül

Plankalkül foi importante porque apresentou ideias bastante avançadas para sua época, mesmo não tendo sido implementada naquele momento.

Entre os recursos antecipados estavam estruturas de dados, tipos e operações estruturadas. Um exemplo importante é o uso de estruturas para representar dados de maneira organizada. Essas ideias ajudaram a antecipar conceitos que posteriormente apareceriam em linguagens de programação mais desenvolvidas.

3. Short Code, Speedcoding e A-0/A-1/A-2

As três iniciativas buscavam facilitar a programação dos primeiros computadores, mas utilizavam estratégias diferentes.

O Short Code permitia representar operações de forma mais simples do que escrever diretamente instruções de máquina. O Speedcoding também buscava facilitar a programação, oferecendo recursos que diminuíam a quantidade de código necessário. Já A-0, A-1 e A-2 foram sistemas desenvolvidos para automatizar a tradução de programas.

Não é correto chamá-los simplesmente de compiladores modernos porque os recursos, técnicas e capacidades desses sistemas eram muito mais limitados. Eles representam etapas iniciais da evolução da tradução automática de programas.

4. Fortran

Quando Fortran foi desenvolvida, muitos programadores acreditavam que o código escrito manualmente em linguagem de máquina ou assembly seria mais rápido do que um programa traduzido automaticamente.

Por isso, o projeto precisava demonstrar que um compilador poderia produzir código suficientemente eficiente. Se o desempenho fosse bom, os programadores poderiam escrever programas com muito menos esforço e tempo.

Assim, Fortran buscava equilibrar desempenho e produtividade. Isso foi fundamental para sua adoção, principalmente na área científica.

5. Lisp e Fortran

Fortran e Lisp foram criadas para objetivos bastante diferentes.

Fortran surgiu principalmente para cálculos científicos e numéricos. Por isso, trabalhava fortemente com números e operações matemáticas.

Lisp, por outro lado, foi desenvolvida para processamento simbólico. Sua estrutura baseada em listas permitia representar e manipular informações de maneira bastante flexível.

Portanto, Fortran favorecia principalmente computação numérica, enquanto Lisp favorecia processamento simbólico, recursividade e manipulação de estruturas.


6. Java e o crescimento da Web

Java não foi criada originalmente pensando na Web. Seu desenvolvimento estava relacionado a outros tipos de dispositivos e aplicações.

Entretanto, o crescimento da Web criou um novo contexto no qual características de Java, como portabilidade e segurança, passaram a ser muito valorizadas.

Isso mostra que uma linguagem pode mudar de importância conforme o ambiente tecnológico muda. Uma tecnologia que não foi criada para determinado objetivo pode posteriormente se tornar muito relevante para ele.

7. Perl, JavaScript, PHP, Python, Ruby e Lua

Embora todas possam ser classificadas como linguagens de scripting, elas possuem origens e características diferentes.

Perl: surgiu com forte foco em processamento de textos e administração de sistemas.
JavaScript: ganhou destaque com a necessidade de criar páginas Web interativas.
PHP: foi direcionada principalmente ao desenvolvimento Web no lado do servidor.
Python: buscou simplicidade, legibilidade e utilização geral.
Ruby: enfatizou produtividade e flexibilidade, tornando-se bastante utilizada no desenvolvimento Web.
Lua: foi projetada como uma linguagem leve e extensível, sendo muito utilizada incorporada a outros sistemas.

Portanto, chamar todas simplesmente de "linguagens de scripting" não significa que tenham o mesmo propósito ou funcionamento.

8. C#

C# foi desenvolvida dentro do ambiente .NET, buscando oferecer uma linguagem moderna e integrada à plataforma.

Uma decisão importante foi utilizar gerenciamento automático de memória, semelhante ao que ocorre em Java. Isso reduz a necessidade de o programador controlar manualmente a memória.

Outra característica é a integração com recursos do ambiente .NET, permitindo que a linguagem trabalhe com uma plataforma comum de execução e bibliotecas.

Em comparação com C++, C# busca reduzir parte da complexidade associada ao gerenciamento manual e aos recursos de baixo nível. Em relação a Java, compartilha a ideia de uma plataforma gerenciada e de maior segurança para o desenvolvimento.

9. XSLT e JSP

XSLT recebe documentos XML como entrada e utiliza regras para transformar esses dados em outra representação, como HTML.

JSP permite combinar elementos de programação com marcação para gerar páginas Web dinamicamente.

A diferença principal está no processo:

XSLT: entrada XML → transformação → saída;
JSP: código/estrutura da página → processamento no servidor → página gerada.

Ambas podem ser consideradas híbridas porque misturam elementos de marcação e programação/processamento.

10. Linha do tempo das linguagens

Um exemplo de linha de influência é:

ALGOL → Pascal → C → C++ → Java

As relações não são apenas cronológicas:

ALGOL → Pascal: influência na programação estruturada e na organização dos programas.
Pascal → C: influência na tradição de linguagens imperativas e estruturadas.
C → C++: influência direta, pois C++ foi desenvolvida mantendo compatibilidade e conceitos de C.
C++ → Java: influência nos conceitos de orientação a objetos e na sintaxe.

Podemos ainda considerar outra linha:

Lisp → linguagens funcionais modernas, mostrando a influência de conceitos relacionados ao processamento simbólico e à programação funcional.
